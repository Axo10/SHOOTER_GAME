# React Shooter Game

A simple browser shooter built with HTML, CSS, JavaScript, and React.

## How to play

- Open `index.html` in your browser.
- Move left and right with Arrow keys or A/D.
- Press Space to shoot enemies.
- Survive as long as possible and earn points.

## Files

- `index.html` - game shell and React import.
- `style.css` - layout and visual style.
- `app.js` - shooter game logic and animation.
